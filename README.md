# Приглашение на юбилей

Одностраничное адаптивное приглашение на 80-летний юбилей в Алматы.

Откройте `index.html` в браузере, чтобы посмотреть сайт. Для персонального обращения используйте параметр ссылки: `?name=Айгуль`.
